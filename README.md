# Visual App Workspace

This is the canonical source template for Worka Visual App workspaces.

Worka materializes this Git source before starting the collaborative Visual
Software Development Lifecycle (vSDLC). The FST generates requirements,
designs, A2UI screens, and release evidence inside the materialized workspace.
It does not compile a Rust/Fission application.

The complete pinned A2UI v1.0 candidate specification is available at
`specification/v1_0`. The FST must use those local files as its protocol,
catalog, schema, example, and validation context rather than searching another
checkout or relying on model memory.

Advanced App workspaces use the separate autonomous SDLC template. This template
is only for the collaborative Visual App vSDLC.
